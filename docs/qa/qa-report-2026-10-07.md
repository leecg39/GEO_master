- Vitest: **40개 파일, 205개 테스트**. 회귀 테스트는 수정 전 실패를 확인한 뒤 수정 후 통과를 확인했다.
- TypeScript: `npm run typecheck` (`next typegen && tsc --noEmit`).
- ESLint: `npm run lint`, 경고 0.
- 프로덕션: `npm run build`, 격리 DB로 `npm start -- --port 3200` 실행.
- Ego Lite: 1440×1000 및 375×812에서 19개 화면을 순회하고 제목·폼·가로 넘침 점검. 구독 시작/확인, ALL IN mock 실행, 모바일 메뉴, 테마 전환 및 새로고침 유지 확인.
- 프로덕션 HTTP: 페이지 19개 200, JSON 형식 415 및 cross-site 403 차단, live checkout 503, 진단·점유율 JSON/CSV/PDF 6종과 PDF 1.7 시그니처, schema v2 스냅샷. [29개 검사 결과](production-smoke-2026-10-07.json).
- 적대적 검토: 정상 경로 외 실패 응답, 반복 요청, 만료, 모드 오설정, 프로젝트 전환 및 응답 순서 역전을 직접 공격 입력으로 구성했다. 독립 외부 모델 검토는 수행하지 않았다.

## 검증 한계와 기존 기능 범위

- 운영 결제 승인 검증과 Google OAuth·GSC/GBP 동기화는 구현되지 않았다. 운영 결제는 차단하고, 수동 위치는 미연결로 표시하도록 수정했다. 이 결과를 유료 서비스 출시 승인으로 해석해서는 안 된다.
- TalorData·Firecrawl과 LLM 유료 API의 실제 호출은 수행하지 않았다. SEMForge 흐름은 명시적 mock 공급자 및 실패 주입으로 검증했다.
- 현재 Firecrawl 사이트 진단은 `/v1/map` URL 발견 목록을 기반으로 한 휴리스틱이다. 저장되는 페이지 상태 및 건강 점수는 실제 개별 페이지 HTTP·성능 측정 결과가 아니다. 본문 수집 기반 진단은 별도 구현 범위다.
- 대시보드 전용 평가 스크립트는 포트 3000을 고정 사용하므로 격리 QA 서버의 점수로 사용할 수 없었다. 실행 결과 89/104 중 정적 레이아웃·검증 항목은 통과했고, API 항목 15점은 평가 대상 서버 불일치로 획득하지 못했다. 평가 스크립트는 수정하지 않았다.
- 기존 미추적 `.commandcode/`, `GEO_master_Qshop_Integration_Plan.md`, `qshop.pdf`는 변경·커밋하지 않았다.
