# 프론트엔드 RSI — 2026-10-07

목표: 19개 경로의 키보드 사용성, 폼 접근성, 반응형 레이아웃, 명암 대비 개선.
Ego Lite를 사용한다(사용자 브라우저 선호). 별도 QA DB, localhost:3100, 예약 worker 중지. 외부 유료 API 호출 금지.

## 고정 평가
- `../eval/`은 베이스라인 커밋 이후 변경하지 않는다. 기존 `autoresearch/eval/`과 `meta_eval/`도 수정 금지.
- error .35 / dom .25 / form .25 / visual .15. 가중치 변경 없이 전후 비교한다.
- 19개 경로 × 데스크톱 dark/light, 모바일 375/320 dark. axe-core 4.13.0 및 실제 DOM 크기, 명명, 내비게이션 의미 검사.
- 폼: llms 초안 생성/검증, 백업 이름 변경/저장, 체크리스트 메모 저장, 메뉴·드로어·확인 창 키보드 동작.
- 개발 도구 Agentation/Next overlay는 제품 평가 영역에서 제외하되 앱 콘솔 오류는 기록.
- 완전한 WCAG 준수 또는 외부 제공자 실서비스 검증을 의미하지 않는다.

## Inner Loop
가설 1개 → 변경 전 증거 → 실험 커밋 → 대상 경로 동일 평가 → 개선 keep / 동일·악화 revert → 기록.
사용자 변경 보호를 위해 reset --hard 대신 해당 실험 커밋만 revert.
전체 페이지 기준 점수는 전체 재실행에서만 보고한다. 국소 실험은 관련 실패 검사 개선과 회귀 여부로 판정.

## 수정 범위
`src/components/`, `src/app/globals.css`, `src/hooks/`, 관련 회귀 테스트만.
API/DB/지표 계산, 미구현 결제·OAuth, 데이터 소스는 수정 금지.
디자인 방향(보라/라임, 대시보드 2열)은 유지한다.

## Outer Loop
실험 결과를 분석해 우선순위만 조정한다. 포화 지표를 인위적으로 재정의하지 않는다.
키보드 안전성 → 접근 가능한 이름 → 작은 화면 → 대비 → 오류/상태 안내 순으로 연구한다.
