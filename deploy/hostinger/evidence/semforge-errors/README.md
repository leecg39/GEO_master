# SEMForge 측정 오류 진단 및 수정

대상: https://geo.soverin.cloud/semforge

확인일: 2026-10-07 (KST)

프로젝트: AX 브릿지 / 이음 파트너스 / axbridge.soverin.cloud

## 확인된 원인

| 기능 | 실제 실패 원인 | 수정 후 동작 |
| --- | --- | --- |
| AI SEO (SERP) | TalorData 이용권 만료 | 만료 원인을 표시하고 첫 실패 이후 나머지 쿼리는 미실행 처리 |
| 포지션 추적 | 동일한 TalorData 이용권 만료 | 원인 표시, 기존 가시성과 갱신 시각 보존 |
| 지역 SEO / Map Rank | 동일한 TalorData 이용권 만료 | 원인 표시, 기존 가시성과 갱신 시각 보존 |
| 사이트 진단 | Firecrawl 크레딧 소진 | 충전 안내, 기존 건강 점수·페이지·성공 시각 보존 |
| 도메인 개요 | 자체 조회 오류 없음 | 저장된 자료의 요약 조회 정상 |

TalorData 실제 응답은 HTTP 200이지만 본문은 `{"code":400,"data":"Package has expired!"}`였습니다. 기존 구현은 HTTP 상태만 확인하여 이를 빈 검색 결과로 분류했습니다.

Firecrawl의 잔여 크레딧 조회 결과는 `remainingCredits: 0`, `planCredits: 1000`이었습니다. 실제 사이트 진단 요청에서도 크레딧 부족 응답을 확인했습니다. 키 누락이나 도메인 오타 때문에 발생한 오류가 아닙니다.

## 수정 내용

- HTTP 200 내부의 공급자 오류 코드를 검사하고 만료·잔액 부족·인증 실패·요청 제한을 구분합니다.
- 외부 호출에 30초 제한을 추가하고 연결 실패·시간 초과 메시지를 구분합니다.
- 계정 전체를 막는 오류가 나오면 동일 수집 묶음의 나머지 키워드를 미실행 처리합니다.
- ALL IN은 AI SEO에서 계정 차단을 확인하면 뒤의 포지션·지역 SEO 호출을 건너뜁니다. 별도 공급자인 Firecrawl 진단은 계속 확인합니다.
- 일부만 성공하거나 전체 실패한 순위 수집은 새 가시성을 계산하지 않습니다. 기존 집계와 갱신 시각을 유지합니다.
- 개별 측정 화면에도 실제 원인을 표시합니다.
- 차단을 영구 저장하지 않으므로 계정 갱신 후 다시 측정할 수 있습니다.

## 검증

- 전체 자동 테스트: 45개 파일, 257개 테스트 통과.
- 실제 공급자 응답을 재현하는 회귀 테스트: 12개 통과. 이용권 갱신 후 재실행 성공, 중복 호출 중단, 부분 실패 시 집계 보존 포함.
- TypeScript 검사, 변경 파일 ESLint, diff 공백 검사 통과.
- 운영 Docker 프로덕션 빌드 및 컨테이너 healthy 확인.
- 운영 API 점검: 43개 검사 통과. SEMForge 6개 화면, 4개 개별 수집 경로, 기존 데이터 보존, 비인증 접근 차단 및 공개 OG 응답 포함.
- Ego Lite에서 실제 ALL IN 버튼을 실행하여 만료·크레딧 부족 안내, 후속 측정 건너뜀, 실패 시 0% 집계 미표시를 확인했습니다.

참고: 운영 사이트 진단 비교의 최초 검증에서 조회 시마다 바뀌는 `fetchedAt`까지 비교하여 검사 스크립트가 실패했습니다. 보존 대상인 캠페인·진단 결과를 비교하도록 검증을 수정했고 43개 검사가 통과했습니다.

## 남은 조치

앱의 오류 처리는 수정했지만, 외부 계정의 만료와 크레딧 소진은 아직 해결되지 않았습니다. 실제 측정 재개에는 연결된 TalorData 계정의 SERP 이용권 갱신과 Firecrawl 크레딧 충전이 필요합니다. 결제나 충전을 수행하지 않았습니다.

현재 두 API 키는 서버 환경 설정에서 우선 적용됩니다. 다른 계정으로 교체할 경우 운영 서버의 연결 키도 교체해야 합니다. 기존 계정의 이용권·크레딧만 갱신하면 코드 변경 없이 다시 측정할 수 있습니다. 갱신 후 실제 성공 결과는 아직 확인할 수 없습니다.
