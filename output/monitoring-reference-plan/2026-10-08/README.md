# 모니터링 레퍼런스 적용안

15개 레퍼런스 이미지의 관찰 내용과 현재 소스 구조를 연결한 후속 설계다. 핵심은 **질문 → 측정 시점 → 4개 AI 서비스 → 원문·출처** 탐색이다.

HTML 파일은 브라우저에서 바로 열 수 있는 독립 파일이다. 외부 패키지나 API 연결이 필요 없다.

## 먼저 적용할 기능

1. 그래프 시점 또는 날짜 선택 → 해당 질문·실행의 저장 응답 조회.
2. ChatGPT·Claude·Gemini·Grok 카드 → 일반/검색 조건·반복별 원문·출처.
3. 질문 검색·현재 언급률/증가 폭 정렬, 자사 링 강조, 브랜드 고정색.

Perplexity와 이미지의 14개 모델 구성을 추가하지 않는다. 검색 조건을 별도 서비스로 세지 않으며 실제 검색 수행 여부를 표시한다. 기존 저장 구조를 활용하므로 우선 기능에는 신규 LLM 호출이나 DB 마이그레이션이 필요 없다.

## 시안 사용법

전체 성과에서 질문을 고르고, 그래프의 자사 점이나 날짜 선택기로 과거 실행을 선택한다. 카드 제목을 누르면 원문이 펼쳐진다. 상단 버튼으로 라이트/다크를 전환한다. 질문 목록은 검색·정렬할 수 있으며, 모바일에서는 목록을 접을 수 있다.

이 시안은 가상 브랜드·5개 질문·6회 실행·서비스별 1회 응답으로 만든 예시다. 실제 측정 성과가 아니다. 앱에 붙일 상세 API·반복 응답 페이지 처리·실패/거절 상태·URL 복원은 적용 명세에 정의했으며 이 HTML에 구현된 제품 기능으로 간주하지 않는다.

## 브라우저 확인

Ego 브라우저에서 1440px 데스크톱 다크 및 390px 모바일 라이트 화면을 확인했다.

- 과거 실행 선택 시 응답 요약은 `1/4 · 25.0%`로 변경되고, 기간 비교 `25.0% → 75.0%`는 유지됐다.
- 자사 그래프 포인트를 Enter로 선택할 수 있었다.
- 질문 검색 후 목록만 줄어들고 선택된 상세는 유지됐다.
- 4개 응답 카드, 원문 펼치기/접기, 테마 전환을 확인했다.
- 모바일 페이지 가로 넘침이 없었다. 작은 화면에서도 축 글자를 읽을 수 있도록 차트 좌표계를 조정했다.
