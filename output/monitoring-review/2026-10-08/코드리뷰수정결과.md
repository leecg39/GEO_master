요청한 기존 4개 LLM(ChatGPT, Claude, Gemini, Grok)을 유지했다. 확인된 기능 오류 4건을 수정하고 회귀 검사를 추가했다.

## 발견 및 수정

| 우선순위 | 재현된 문제 | 수정 |
| --- | --- | --- |
| P1 | 종료일이 `9999-12-31`일 때 다음 달 ISO 문자열이 확장 연도로 바뀌면서 월 반복이 끝나지 않았다. 동기 집계이므로 서버 요청 처리가 멈출 수 있었다. | 월 순회를 숫자 시각으로 종료하고, 조회 상한을 SQLite 날짜 연산으로 계산했다. 지원 범위는 0001~9999년이며 기본 시작일도 하한을 지킨다. |
| P2 | Perplexity 등 지원하지 않는 모델만 실행한 기록이 기준·현재 실행과 월별 횟수에 포함됐다. 정상 모델의 비교가 미측정으로 바뀔 수 있었다. | 기존 4개 모델 응답이 있는 실행만 포함한다. 원문이 아예 없는 과거 실행은 기존 미측정 처리로 유지한다. |
| P2 | SQLite의 시간대 없는 UTC 날짜를 JavaScript가 로컬 시간으로 읽었다. KST 월요일 경계에서 주간 집계 대상이 어긋나 조회 오류가 발생했다. | DB 조회 시 명시적 UTC 문자열로 정규화한 뒤 KST 주간·월간 집계에 사용한다. |
| P2 | 질문 세트 생성 중 프로젝트가 바뀌어 편집창이 닫혀도 후속 질문 저장이 계속됐고, 오래된 완료 콜백이 새 편집창을 닫을 수 있었다. | 편집창 해제 시 요청을 중단하고, 응답 이후에도 중단 상태를 검사한다. 중복 저장과 이전 요청의 후속 처리도 막는다. |

수정 전 회귀 검사에서 지원 외 모델 집계, UTC 날짜 처리, 오래된 저장 요청 문제가 실패했다. 최대 연도 검사는 무한 반복을 재현하여 해당 테스트 프로세스를 종료한 뒤 수정했다.

빌드된 서버를 별도 QA 데이터베이스와 로컬 3102 포트에서 실행해 확인했다. 아래 응답 시간은 이 환경에서 한 번 측정한 값이며 성능 보장 수치는 아니다.

| API 요청 | 실제 결과 |
| --- | --- |
| `start=9999-12-01&end=9999-12-31` | HTTP 200, 632ms, 무한 반복 없음 |
| `end=0001-01-01` | HTTP 200, 134ms, 시작일도 0001-01-01로 제한 |
| `start=0001-01-01&end=0001-01-01&format=csv` | HTTP 200, CSV 응답 |
| `start=0000-01-01&end=0000-01-01` | HTTP 422, 잘못된 입력 거절 |
| 기본 기간 | HTTP 200, 완료 실행 10회, 정확히 4개 모델 반환 |

## 모바일 화면 확인

Ego 브라우저에서 최종 빌드의 390×844 라이트 화면을 확인했다. 차트를 실제 화면 안으로 스크롤한 뒤 자사와 경쟁사 6개 선, 축, 범례가 표시됨을 확인했다. 가로 넘침도 없었다.

이전 전체 페이지 캡처에서 화면 밖 차트가 비어 보인 현상은 캡처 과정에서 발생했다. 실제 화면의 차트 렌더링 오류로 재현되지 않아 차트 코드를 불필요하게 변경하지 않았다.

- [검증한 모바일 라이트 차트](./mobile-light-chart-visible.png)

화면 데이터는 QA용 합성 데이터이며 실제 고객 성과가 아니다. 편집 요청 중단은 서버가 이미 반영한 변경을 되돌리지 않는다. 해당 경우 재조회로 실제 저장 상태를 확인한다.
