# AI 언급 모니터링 구현·검증 결과

검증일: 2026-10-08

## 구현 결과

전용 화면 `/monitoring`과 조회·CSV API `/api/monitoring`을 구현했다. 사이드바의 **AI 언급 모니터링**에서 접근한다. 기존 대시보드는 유지했다.

- **ChatGPT·Claude·Gemini·Grok 4개** 유지. Perplexity 연동·선택 항목을 추가하지 않았으며 지원 외 provider 응답은 집계에서 제외한다.
- 질문 원문 목록, 추가·수정, 기준→현재 언급률·모델 수·평균 등장 순위.
- 전체 성과의 주별 언급률, 변화, 4축 레이더와 4개 모델 비교 표.
- 질문별 자사·경쟁사 표, 실행별 추이, 자사 고정, 상위 경쟁사 기본 표시, 체크박스와 더보기.
- 기본 최근 12주, 최대 366일 조회, 월별 완료 실행 수, URL 기반 기간·질문 선택 복원.
- 모바일 질문 목록 접기, 다크·라이트 테마, 수치 표와 미측정 상태.
- 같은 집계 함수에 기반한 UTF-8 BOM CSV 내보내기와 수식 삽입 방어.

기존 저장 응답을 현재 브랜드·별칭·등록 경쟁사 설정으로 재집계한다. 실패·거절은 언급률 분모에서 제외한다. 질문 수정 전 원문의 측정 이력은 별도로 보존한다. 미측정은 0%와 구별하며 실행이 한 번뿐이면 비교값을 만들지 않는다. 새 LLM 호출이나 DB 스키마 변경은 없다.

전체 lint 오류를 낸 배포 보조파일은 이번 구현 파일이 아니며 수정하지 않았다. 기존 작업 중이던 `layout.tsx`, `ThemeInitScript.tsx`, 테마 테스트와 기타 파일도 유지했다.

집계 테스트는 성공 응답 가중치, 중복 언급, 별칭 재집계, 도메인만 나타난 응답, 질문·모델 누락, 단일 실행, 질문 수정, 중복 등록, KST 날짜 경계, 다른 프로젝트 격리, 100개 초과 실행, 인증, CSV 일치 및 잘못된 필터를 검증한다. 화면 테스트는 오래된 요청 무시, 프로젝트 변경 이벤트, URL 선택 복원, 오류 복구, 수정 충돌, 내보내기 오류, 모바일 목록을 검증한다.

## 실제 브라우저 검사

Ego Lite TaskSpace 37에서 최종 프로덕션 빌드의 별도 로컬 서버를 사용했다. 테스트 DB는 `/tmp/geo-monitoring-qa-39N326/qa.db`이며 사용자 운영 데이터와 분리했다. 참조 이미지의 질문 5개와 합성 응답으로 10회 실행을 구성했다. **스크린샷의 수치는 검증용 예시이며 실제 LLM 측정 성과가 아니다.**

| 시나리오 | 결과 |
| --- | --- |
| 1600px 데스크톱 전체·질문 상세 | 정상 표시, 모델 표 정확히 4행 |
| 390px 모바일 다크·라이트 | 가로 페이지 넘침 없음, 질문 목록 접기·펼치기 정상 |
| 모바일 날짜 입력 | 잘리던 날짜 필드를 전체 폭으로 수정 후 확인 |
| 브랜드 목록 | 기본 10개 표시, 13개로 펼치기 확인 |
| 추이 선택 | 자사 고정, 기본 6개에서 체크 후 7개 표시 확인 |
| URL 복원 | 선택 질문 새로고침·뒤로가기 복원 확인 |
| 날짜 필터 | 2026-09-01~2026-09-30으로 적용, 선택 질문 유지 |
| 질문 추가 | 저장 후 미측정 질문으로 표시 |
| 기존 질문 수정 | 새 문장 미측정, 이전 문장 `과거 질문 · 이력 보존` 확인 |
| 프로젝트 전환 | 이전 프로젝트 질문 데이터 섞임 없음 |
| 빈 프로젝트 | 모델 4행 모두 `—`, 첫 질문과 기본 질문 세트 생성 성공 |
| CSV 실제 다운로드 | 전체 및 질문별 파일 저장, BOM·행 구성 확인 |

전체 CSV의 검증용 언급률은 **24.5% → 68.4% (+43.9%p)**로 화면과 일치했다. 전체 CSV에 모델 4행, 질문 CSV에 등록 브랜드 13행 및 실행 추이 130행이 있다. CSV는 선택 질문의 모든 등록 브랜드를 내보내며 차트 체크박스는 표시만 제어한다.

기존 개발 앱 `http://127.0.0.1:3101/api/monitoring`에서도 읽기 전용 확인을 수행했다. HTTP 200, 완료 실행 7개·질문 6개, ChatGPT·Claude·Gemini·Grok 반환을 확인했다. 합성 질문과 응답은 사용자 데이터에 삽입하지 않았다.
